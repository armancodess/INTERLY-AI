# 🎤 INTERLY AI – AI Interview Agent

INTERLY AI is a full-stack AI-powered interview platform that helps users practice technical and HR interviews through interactive mock interview sessions. Powered by OpenRouter, it delivers intelligent AI responses, personalized feedback, secure authentication, and a modern user experience.

🔗 **Live Demo:** https://interly-ai-client.onrender.com/

---

## 🚀 Tech Stack

- React 19
- Vite
- Tailwind CSS
- Redux Toolkit
- Node.js
- Express.js
- MongoDB
- Firebase Authentication
- OpenRouter API
- Razorpay
- JWT

---

## ✨ Features

- 🤖 AI-powered mock interviews
- 🎤 Technical & HR interview practice
- 📝 Personalized AI feedback
- 🔐 Secure Email & Google Authentication
- 💳 Premium subscription with Razorpay
- 📱 Fully responsive modern UI
